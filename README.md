# Python Development Practice

This repository contains a collection of Python development assignments, practical exercises, and projects completed during my Python development practice.

The projects cover Python programming fundamentals as well as web development using Flask, database management with SQLite and SQLAlchemy, REST API development, HTML/Jinja2 templating, CSV data processing, and data visualization.

## 🛠️ Technologies Used

- **Python** – Core programming and problem solving
- **Flask** – Web application development
- **Flask-SQLAlchemy** – Database integration and ORM
- **Flask-RESTful** – REST API development
- **SQLite** – Database management
- **Jinja2** – Dynamic HTML templating
- **HTML/CSS** – Web page structure and styling
- **Matplotlib** – Data visualization
- **CSV** – Data storage and processing

## 📚 Projects & Topics

### Python Fundamentals
Practice programs covering Python syntax, functions, file handling, data processing, command-line arguments, and basic programming concepts.

### Flask Web Applications
Multiple Flask applications demonstrating:

- URL routing
- GET and POST requests
- Form handling
- Jinja2 templates
- Static files
- Redirects and sessions
- Dynamic web pages

### Database Applications
Applications using **SQLite and SQLAlchemy** to implement database-driven functionality, including:

- Creating and managing records
- CRUD operations
- Students and courses
- Course enrollments
- Database relationships

### REST API
A Flask-RESTful application implementing APIs for managing students and courses, including operations for creating, retrieving, updating, and deleting resources.

### Data Processing & Visualization
Projects involving CSV files, data analysis, report generation, and visualization using Matplotlib.
